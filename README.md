##Student Digital Life & Academic Performance##

An exploratory data analysis project investigating how students' digital habits, daily activities, study behavior, and lifestyle relate to academic performance.

📊 Project Overview

This project explores a student dataset containing information about:

Study and sleep habits

Smartphone, social media, gaming, and streaming usage

Exercise and daily activities

Class attendance and assignment completion

Motivation and caffeine intake

Final exam performance

Demographic and lifestyle information

The goal is to explore patterns and relationships between students' digital lifestyles, daily routines, study behavior, and academic performance.

Note: This project focuses on exploratory data analysis and interactive data visualization rather than building a predictive machine learning model.

📚 Dataset

The dataset contains more than 15,000 student records and includes variables such as study hours, smartphone usage, social media usage, gaming, streaming, sleep, exercise, attendance, assignment completion, caffeine intake, mental health status, parent education level, internet quality, motivation level, and final exam score.

Dataset source: Public Kaggle competition

🔍 Analysis

The Jupyter Notebook includes:

Dataset inspection and descriptive statistics

Duplicate checking

Analysis of students' daily time allocation

Smartphone usage vs. study time analysis

Study-hours distribution

Comparison of students with similar study hours but different digital habits

Correlation analysis between lifestyle factors and final exam scores

Study time vs. final exam score analysis

Study and sleep relationship analysis

Student performance profiling

Interactive data exploration through a Plotly Dash dashboard

1. Clone the repository

2. Install the required libraries

pip install -r Requirements.txt

3. Run the dashboard

python app.py

Then open the local address shown in your terminal.
